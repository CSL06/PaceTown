# Campus daylight v2 candidate

`campus-daylight-v2.png` was generated with the built-in ChatGPT ImageGen workflow
using the current runtime campus as the edit target.

The prompt requested a bright late-morning relight while preserving the established
pixel-art architecture and composition: pale-blue sky, cream sunlight, fresher
greens, lifted stone paths, gentler shadows, and less navy/burgundy/dusk-orange.

This is an art-direction candidate, not a drop-in runtime replacement. Generative
editing can make small geometric changes even when preservation is requested. Before
shipping it, compare landmarks and walkable boundaries against the current collision
map, then either update collision data or create a geometry-locked recolor from the
current source image.
