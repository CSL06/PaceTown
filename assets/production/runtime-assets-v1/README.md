# PaceTown Runtime Assets V1

Generated deterministically on the 32 px world grid with the canonical PaceTown palette.

- Production sheets: 62
- Every atlas uses exact integer cells and RGBA output.
- Interactive sheets include idle/highlighted/active/reduced-motion states.
- Mini-game backgrounds are palette-reduced full-screen scenes; foregrounds are separate transparent atlases.
- The aggregate manifest is `pacetown-runtime-assets-v1-manifest.json`.
